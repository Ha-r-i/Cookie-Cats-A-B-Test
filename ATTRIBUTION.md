# Sources and implementation

- **Dataset:** [Mobile Games A/B Testing by Aurelia Sui](https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing).
- **Reference analysis:** [Quantique-Realm/cookie-cats-ab-test](https://github.com/Quantique-Realm/cookie-cats-ab-test), inspected at commit `5fff3ae4e17de6cecb31a46650110bc1bc2f8f77` on 16 November 2026.

This is a separately written, AI-assisted reproduction of the public Cookie Cats experiment.
The reference motivated the question and provides the pinned data mirror.
Its notebook, source code, prose, and figures are not copied into this repository;
no project license was listed when inspected. Figures and reports here are generated
by this repository's own analysis.

The main retention analysis includes all assigned players, including the maximum
game-round observation. This differs from the reference's outlier-filtered main
analysis, so small numerical differences are expected. Analysis choices were made
with the public findings already visible and are not a preregistered experiment plan.
